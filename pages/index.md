# SW CloudCalendar

SW CloudCalendar displays read-only calendars in WordPress. Google Calendar, Microsoft 365 and ICS events are synchronised to the site in the background; viewing these calendars does not contact their providers. Other plugins can supply local calendars directly without another stored copy.

- [Getting started](./getting-started.md): install the plugin and publish a first calendar using a connection, source and view.
- [Connections](./connections.md): connect an ICS feed, Google account/public calendar, Microsoft 365 account or an available local source plugin.
- [Sources and attachments](./sources.md): choose calendars, set visibility, synchronisation windows and file policies.
- [Views and embedding](./views.md): combine sources in lists, cards or a month grid; add a shortcode or block and configure navigation and filters.
- [Templates](./templates.md): use presets or the visual/HTML editor to change event, container and detail layouts.
- [Configuration and operation](./configuration.md): set up background processing, encryption, private storage, logging and removal.
- [Troubleshooting](./troubleshooting.md): check synchronisation, authorisation, output and file delivery.
- [Changelog](./Changelog.md): documentation changes and attributable release notes.

The plugin reads calendars; it does not edit appointments at their providers. Public, signed-in and role-restricted visibility applies to whole sources. Review [visibility and caching](./views.md#protected-calendars-and-preloading) before publishing non-public data.
